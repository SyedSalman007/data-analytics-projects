# Customer Churn Project

## Files
- `customer_churn_analysis.py`: end-to-end churn analysis pipeline.
- `01_customer_churn_analytics.ipynb`: notebook wrapper to run the pipeline.
- `output/`: generated analysis outputs and charts.

## Run
From repo root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 notebooks/customer_churn_analysis.py
```

Or open notebook:

```bash
jupyter notebook notebooks/01_customer_churn_analytics.ipynb
```
