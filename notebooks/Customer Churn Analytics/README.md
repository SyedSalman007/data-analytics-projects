# Customer Churn Project

## Files
- `customer_churn_analysis.py`: end-to-end churn analysis pipeline.
- `01_customer_churn_analytics.ipynb`: notebook wrapper to run the pipeline.
- `output/`: generated analysis outputs and charts.

## Run
From repo root:

```bash
scripts/bootstrap_venv.sh
source .venv/bin/activate
python notebooks/Customer\\ Churn\\ Analytics/customer_churn_analysis.py
```

Or open notebook:

```bash
jupyter notebook notebooks/Customer\\ Churn\\ Analytics/01_customer_churn_analytics.ipynb
```
